## 城事通：接入百度地图实时底图

把 `src/components/IssueMap.vue` 从手绘 SVG 示意图改为百度地图 JS API（WebGL 版）真实底图，保留原有 `issues` / `selected` 输入与 `select` 事件接口，SVG 示意图降级为回退方案。

### 关键结论（后续接后端时仍然适用）

- **演示数据是 GCJ-02**，不是 BD-09。已用对照实验确认：`新街口地铁站北出口`（118.783, 32.043）转成 BD-09 后落在新街口地铁站，不转换会偏约 922 米。数据坐标系开关在 `src/utils/coord.ts` 的 `SOURCE_COORD_SYSTEM`（当前 `"gcj02"`），接后端时按后端实际返回值修改。
- **百度 SDK 必须用 `index.html` 里的静态 `<script>` 加载**。`api.map.baidu.com/api?type=webgl` 返回的加载器内部用 `document.write`，运行时动态插入脚本会清空页面。
- 密钥走 Vite 的 HTML 环境变量替换：`index.html` 里写 `ak=%VITE_BAIDU_MAP_AK%`，真实值放在 `.env.local`（`.gitignore` 的 `*.local` 覆盖）。`.env` 里保留空的 `VITE_BAIDU_MAP_AK` 以消除构建警告。
- 标点图标用内联 SVG data URI + `BMapGL.Icon(url, size, {anchor})`，按 progress 着色，选中/悬停换放大的变体，不引用官方 demo 图片。
- 自定义图例已抬高到 `bottom: 62px`（`.map-canvas.is-live`），避免遮挡百度地图自身的版权标识；实时模式下隐藏自绘的 `N↑` 指北针（WebGL 底图可旋转，指北针会失真）。

### 验证方式

Windows 上不装 Playwright，直接用系统自带 Edge 无头截图：
`msedge.exe --headless=new --disable-gpu --no-sandbox --window-size=1440,1420 --virtual-time-budget=25000 --user-data-dir=<tmp> --screenshot=<png> <url>`。
注意 `--virtual-time-budget` 太短（9000）时高缩放级别的瓦片可能来不及渲染，用 25000 稳定。截图产物见 `docs/baidu-map-preview.png`。
