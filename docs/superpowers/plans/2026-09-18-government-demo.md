# 政府端问题协同处置 Demo 实现计划

**Goal:** 实现已确认的地图、问题列表、责任人分配演示。
**Architecture:** Vue 3 + TypeScript。问题数据独立定义；SVG 示意地图按经纬度绘制问题点；根组件管理筛选、选择和本地持久化。
**Tech Stack:** 现有 Vue / Vite，不增加运行时依赖。
**Spec:** 用户已确认的左侧地图、右侧列表、详情抽屉、蓝白政务风设计。

## 约束
- 全部为模拟数据，地图明确标注示意，未接后端。
- 保留提交人、时间、经纬度、图片、类型、描述、责任人、进度字段。
- 状态和分配修改写入 localStorage；存储不可用时提示。

## 实施与验收
- [ ] 数据层：定义 Issue、负责人和 12 条演示数据，校验本地读取的数据。
- [ ] 地图组件：标点、选中、缩放、重置视图，点位与列表联动。
- [ ] 页面：统计、搜索与类型/进度筛选、列表、空状态、详情编辑和图片预览。
- [ ] 验证：npm run build；浏览器检查筛选、分配、保存、刷新持久化及窄屏布局。
- [ ] 文档：说明启动方式、模拟地图边界及后端对接字段。
